# Siddiqui Motors & Rentals

Welcome to Siddiqui Motors and Rentals! We specialize in selling and renting premium cars from international countries including Japan, Pakistan, and more. We aim to provide you with a wonderful experience in finding your perfect vehicle.

## Features

- **Featured Car Listings**: Browse our collection of luxury, sports, and electric vehicles
- **Car Details**: View detailed information and pricing for each vehicle
- **Contact Form**: Get in touch with our team for inquiries
- **Responsive Design**: Fully responsive website that works on all devices

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Hamzaplayz34/Siddiqui-Motors-and-rentals-.git
cd Siddiqui-Motors-and-rentals-
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The website will open in your browser at `http://localhost:3000`

## Building for Production

To create a production build:
```bash
npm run build
```

This creates an optimized build in the `build` folder.

## Technologies Used

- **React** - UI library for building interactive components
- **Tailwind CSS** - Utility-first CSS framework for styling
- **PostCSS** - CSS tool for processing stylesheets
